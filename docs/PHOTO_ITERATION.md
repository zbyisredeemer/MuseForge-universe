# MuseForge Photo Iteration

MuseForge 的真实图片不是“一次生成完成”，而是持续迭代资产。每一轮都以 **真实感、身份差异、构图差异、服装差异、场景一致性** 为核心，不以“文件已经是 WebP”作为完成标准。

## 默认迭代循环

```text
选择当前最弱的一批图片
-> 检查 Prompt / Identity DNA
-> 拉开人物与服装差异
-> 重生成候选图
-> 淘汰同脸 / 假脸 / 塑料皮肤 / 手部异常
-> 选最佳成片
-> WebP
-> 覆盖对应静态资产
-> npm run validate
-> 页面复查
-> 进入下一批
```

## 成片验收门槛

每张照片至少检查：

- 主体必须明确为成年人；
- 与相邻图片相比，脸宽、眼距、鼻型、下颌、下巴和唇比例应有肉眼可见差异；
- 不能只是换发型、换衣服、换背景；
- 避免统一的“网红脸”、娃娃脸、过度 V 脸和极端对称；
- 皮肤保留自然毛孔、纹理和轻微不均匀感，避免塑料磨皮；
- 发际线、碎发、耳朵、牙齿、眼白和睫毛应自然；
- 手指、手腕、肩颈和衣服连接关系正确；
- 背景必须与人物景深和光线方向一致；
- 不允许水印、文字、Logo、明显生成伪影；
- 同一星球连续 4 张不得出现近似构图 + 近似服装 + 近似脸型三项同时重复。

## 自动校验

```bash
npm run validate:assets
npm run validate:identities
npm run validate
npm run build
```

其中：

- `validate:assets`：检查静态资源路径、缺图、重复引用；
- `validate:identities`：检查身份结构组合与 Forest 地域轮换；
- `validate`：一次执行前两项；
- `build`：最终确认 TypeScript 与 Vite 构建。
