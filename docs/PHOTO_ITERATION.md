# MuseForge Continuous Photo Iteration

项目持续迭代只有三个目标：

> **补量、提质、去重复。**

前提永远是保持 Style Bible：

> **明确成年、20～28 岁、年轻、性感、高颜值、高级写真感。**

## 固定循环

```text
读取 regenerationQueue
→ 读取 Style Bible + generation preset
→ 先处理损坏/缺失资产
→ 为最高优先级图片生成多个候选
→ 按颜值/年轻感/性感/真实感打分
→ 做人脸差异复核
→ 只选最好的候选
→ 转换 WebP
→ 校验真实二进制与尺寸
→ 上传 GitHub
→ 更新 Prompt / DNA / resolution
→ queue 标记 replaced
→ 继续下一张
```

## 选图权重

- 颜值 / 吸引力：30
- 年轻感：20
- 高级性感：20
- 真实质感：15
- 摄影与构图：10
- 差异度：5

低于 80 分不入库。

## 资产健康规则

每次图片提交后，`validate:assets` 必须至少检查：

- 图片文件不能异常小；
- WebP 必须有合法 RIFF/WEBP 文件头；
- 不允许损坏候选继续留在候选目录；
- 前台不展示已知损坏资产；
- 图片恢复后再把对应槽位重新发布。

## 不再采用的方向

- 把“成熟感”当作去同脸主要手段；

- 一味追求环境而弱化美女主体。

## 默认“继续”

用户只说“继续”时，直接处理 queue 里下一个最高优先级项目，不重新讨论审美方向。
