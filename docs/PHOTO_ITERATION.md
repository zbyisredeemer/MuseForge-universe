# MuseForge Continuous Photo Iteration

项目持续迭代只有三个目标：

> **补量、提质、去重复。**

前提永远是保持 Style Bible：

> **明确成年、20～28 岁、年轻、性感、高颜值、高级写真感。**

## 固定循环

```text
读取 regenerationQueue
→ 读取 Style Bible + generation preset
→ 为最高优先级图片生成多个候选
→ 按颜值/年轻感/性感/真实感打分
→ 只选最好的候选
→ 转换 WebP
→ 上传 GitHub
→ 更新 Prompt / DNA / resolution
→ queue 标记 replaced
→ 继续下一张
```

## 选图权重

- 颜值 / 吸引力：30
- 年轻感：20
- 高级性感：20
- 真实质感：15
- 摄影与构图：10
- 差异度：5

低于 80 分不入库。

原因不是单纯“同脸”，而是这些图片中存在：

- 年龄感偏离核心风格；
- 性感度或时尚感不足；
- 造型过于保守；
- 场景和元数据不一致；
- 与其他图过度相似。

## 不再采用的方向

以下方向已经废弃：

- 为了差异化引入 30～50 岁人物；
- 把“成熟感”当作去同脸主要手段；
- 用厚重、保守、纪实服装替代性感写真；
- 一味追求环境而弱化美女主体。

## 默认“继续”

用户只说“继续”时，直接处理 queue 里下一个最高优先级项目，不重新讨论审美方向。
