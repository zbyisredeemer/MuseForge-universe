## 第二轮目标

005～011 的新候选图必须至少同时改变以下三项中的两项：

1. 面部骨相：脸宽 / 下颌 / 颧骨 / 下巴；
2. 年龄感：避免全部集中在二十多岁的精致年轻脸；
3. 摄影语言：镜头距离 / 机位 / 朝向 / 动作。

012 暂不为了“统一风格”而重做。它的价值正是与其他图片不统一的身份特征。

## 第一轮视觉审计结论

Forest 005～020 的主要问题已经可以分成三类：

1. **同脸 / 同审美模板**：006、010、013、015、017、020 最明显；
2. **优秀但元数据错位**：016、018、019；
3. **可作为差异化基准**：012、016、018、019。

后续不再采用“20 张全部重做”的策略，而是：

- 保留真正有身份差异的成片；
- 对好图但错标题的资产调整元数据；
- 只对同脸明显或语义错位且没有保留价值的图片重生成。
