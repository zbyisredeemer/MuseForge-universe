# Forest Muse Visual Audit

本文件记录真实 WebP 的视觉检查结论，避免只根据 Prompt 判断质量。检查重点是 **人物是否像同一个人、年龄感是否重复、脸部骨相是否重复、构图是否模板化**。

## 第二轮目标

005～011 的新候选图必须至少同时改变以下三项中的两项：

1. 面部骨相：脸宽 / 下颌 / 颧骨 / 下巴；
2. 年龄感：避免全部集中在二十多岁的精致年轻脸；
3. 摄影语言：镜头距离 / 机位 / 朝向 / 动作。

012 暂不为了“统一风格”而重做。它的价值正是与其他图片不统一的身份特征。
