# Hanfu Muse Series

Hanfu Muse 的目标不是“古装复原图库”，而是：

> **明确成年、20～28 岁、年轻、高颜值、东方古典识别度 + 高级性感写真。**

历史服饰只提供文化与造型语言，最终必须服从 MuseForge Style Bible。

## 系列结构

Hanfu Muse 后续按“服制灵感 × 场景 × 摄影语言”扩展，避免只换颜色和背景。

### 服制灵感

- 唐制灵感：齐胸襦裙、轻纱、明艳色、夜宴/花宴；
- 宋制灵感：褙子、窄袖、清雅色、茶席/庭院/水榭；
- 明制灵感：结构更利落、马面/长衫元素、雨巷/灯市/荷塘；
- 魏晋风灵感：宽袖、月白、山水、帘影、风感；
- 敦煌灵感：青绿、赭石、飘带、壁画色彩，但保持写实摄影而非纯 CG；
- 骑装/丝路灵感：风沙、马场、腰带、披帛，强调年轻时尚而不是纪录片复原。

## 现有 001～020 的数据层改造

从 v0.8 开始，Hanfu 不再共用同一套人物 DNA 和 85mm 镜头。

每个槽位现在拥有独立：

- `ageBand`
- `identityId`
- 脸型 / 颧骨 / 下颌 / 眼型 / 鼻型 / 唇形
- 肤色倾向
- 发长 / 发型 / 纹理
- 辨识特征
- 构图
- 焦段
- 机位
- 光线

目标是从数据源头减少“换衣服不换人”和“20 张都是同一个镜头模板”的问题。

## Batch 02 生成规则

每张真实图必须：

1. 明确成年，视觉年龄落在 20～28 岁；
2. 与 001～020 现有身份明显不同；
3. 至少在脸型、眼型、发型、构图、焦段中的 3 个维度不同；
4. 性感来自肩颈、腰线、材质、姿态和摄影，而不是极端裸露；
5. 汉服识别度足够，但不允许厚重历史纪录片感；
6. 最终输出高质量 WebP；
7. 正式入库前必须经过 `validate:assets`、`validate:identities`、`validate:style`。

## 入库策略

021～030 在真实 WebP 生成完成前不加入 `hanfuMuse.images`，避免：

- 页面引用不存在的静态文件；
- 用 SVG 占位图污染已经真实化的 Hanfu Planet；
- 把“生成计划”误认为“成片”。

真实图完成后按编号逐张加入前台。
