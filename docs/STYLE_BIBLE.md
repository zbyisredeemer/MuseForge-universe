# MuseForge Style Bible

## 1. 项目唯一核心审美

MuseForge Universe 的图片统一服务于一个明确目标：

> **明确成年、年轻、性感、高颜值、高级写真感美女。**

这条规则优先级高于“去同脸”“地域差异”“纪实感”“艺术实验”等其他目标。任何优化都不能把项目带向成熟、老气、保守、粗粝纪实或纯风景方向。

## 2. 人物基线

- 只生成明确成年女性；
- 核心视觉年龄：**20～28 岁**；
- 年轻、有吸引力、女性化；
- 五官精致但允许脸型、眼型、鼻型、发型不同；
- 身材匀称、自然，强调优美腰线、肩颈线、腿部线条等女性美感；
- 皮肤真实但好看：保留轻微毛孔和自然纹理，不做塑料皮肤。

### 不允许

- 未成年人、青少年或模糊年龄；
- 中年/老年视觉方向；
- 为了“去同脸”故意生成不符合项目审美的人物；
- 过度纪实、疲惫、邋遢、老气；
- 统一网红脸、统一 V 脸或完全复制同一个模型身份。

## 3. 性感尺度

项目要的是 **tasteful sensuality / 高级性感**：

推荐：

- 吊带裙、slip dress；
- 修身针织裙；
- 合体连衣裙；
- 露肩、锁骨、背部线条；
- 合理开衩；
- 腰线明确；
- 短裙或适度腿部露出；
- 柔软轻薄材质；
- 自然湿发、风吹发丝等有吸引力的摄影语言。

避免：

- 低俗色情感；
- 极端裸露；
- 纯靠暴露吸引注意；
- 不合场景的夸张情趣化造型。

性感必须和 **年轻、漂亮、时尚、摄影质感** 同时成立。

## 4. 摄影语言

统一基线：

- 9:16 竖版；
- 写实摄影；
- 高级商业写真 / 时尚编辑；
- 35mm / 50mm / 70mm / 85mm 为主；
- 半身、三分之二身、全身轮换；
- 自然光、柔光、黄金时刻、逆光、雾光、月光等；
- 主体始终是美女，环境为人物服务；
- 构图有电影感，但不能把人物缩得看不清。

优先级：

1. 人好看；
2. 年轻性感；
3. 服装和身体线条漂亮；
4. 光影高级；
5. 场景有辨识度；
6. 最后才是“差异化”。

## 5. Planet 风格

### Forest Muse

关键词：

> young sexy forest beauty / romantic nature / premium outdoor fashion editorial

重点：

- 森林、溪流、瀑布、雾、野花、木桥、月夜；
- 绿色、奶油色、酒红、深青色等自然高级色；
- 吊带裙、修身裙、轻薄衬衫、高腰裙、针织裙；
- 清新、浪漫、神秘、轻妩媚。

### Snow Muse

年轻性感 + 雪景反差。服装可以是修身大衣、针织裙、短裙+长靴等，避免臃肿羽绒服占据主要视觉。

### Ocean Muse

年轻性感 + 海边自然光。轻薄长裙、吊带、度假风、湿发、日落逆光是主要语言。

### Hanfu Muse

保持东方古典识别度，同时年轻、漂亮、女性化。重点是剪裁、肩颈、腰线、薄纱层次和高级感，不走厚重历史纪录片路线。

### Tokyo Night

年轻性感 + 都市夜景。修身裙、短外套、长靴、霓虹反光、夜间时尚写真。

## 6. 选图标准

100 分制：

- 颜值 / 吸引力：30
- 年轻感：20
- 高级性感：20
- 真实质感：15
- 摄影与构图：10
- 与已有图片差异：5

规则：

- < 80：淘汰；
- 80～89：候选；
- >= 90：优先入库。

**差异度只有 5 分。不能为了差异牺牲颜值、年轻感和性感。**

## 7. 最终判断

遇到两张候选图时，优先选择：

> **更年轻、更漂亮、更性感、更像高级写真，同时仍然自然真实的那一张。**
